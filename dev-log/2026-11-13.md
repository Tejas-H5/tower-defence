# 2026-11-13 - Debugging tests

Getting the spatial hashmap using tests alone was a pain. 
It is not super obvious how to debug tests, but it looks like tests are just 
methods that can be called. 

Sometimes my genius is... It's almost frightening:

```odin
TESTING :: true

main :: proc() {
	if TESTING {
		run_test()
		return
	}

    // real code here ...
}

// ....

run_test :: proc() {
	t := new(testing.T)
	test_spatial_grid_swap_positions(t)
}
```

Now I can just do `odin build . -debug` and then step it with raddbg.
